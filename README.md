# 🌿 Tierra Media — El Señor de los Anillos & El Hobbit

Sitio web informativo dedicado al universo cinematográfico de **El Señor de los Anillos** y **El Hobbit**.

El proyecto reúne información sobre las películas, personajes, genealogías, lugares, razas, reinos, objetos, curiosidades y otros elementos destacados de la Tierra Media, utilizando una estética visual inspirada en el universo fantástico de J. R. R. Tolkien.

**Sitio web:** https://tierra-media-sepia.vercel.app/

---

## Descripción del proyecto

**Tierra Media** es un sitio web informativo desarrollado como proyecto académico.

El objetivo principal es crear una experiencia de navegación clara y visualmente ambientada en el universo de *El Señor de los Anillos* y *El Hobbit*.

El sitio permite explorar diferentes secciones relacionadas con la saga:

* 🎬 Películas
* 👥 Personajes
* 🌎 Tierra Media
* 🧬 Genealogías
* 🖼️ Galería
* 📜 Curiosidades
* ✉️ Contacto

La navegación cuenta con un menú principal y submenús para acceder rápidamente a las distintas secciones.

---

## 🖼️ Optimización de imágenes

Las imágenes utilizadas en el proyecto fueron optimizadas para reducir su peso y mejorar el rendimiento del sitio.

Entre las técnicas utilizadas se encuentran:

* Conversión de imágenes a **WebP**.
* Reducción de dimensiones cuando el tamaño original era innecesariamente grande.
* Uso de imágenes adecuadas al espacio donde son mostradas.
* Uso de `alt` para describir las imágenes.
* Carga diferida (`lazy loading`) en imágenes donde resulta conveniente.

Esto permite reducir el tamaño de los recursos descargados y mejorar los tiempos de carga.

## Instalación local

Para ejecutar el proyecto de manera local:

### 1. Clonar o descargar el proyecto

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Ingresar a la carpeta

```bash
cd tierra-media
```

### 3. Abrir el proyecto

Al tratarse de un sitio desarrollado con HTML, CSS y JavaScript, puede abrirse directamente desde:

```text
index.html
```

También se recomienda utilizar una extensión como **Live Server** en Visual Studio Code para visualizar correctamente el proyecto durante el desarrollo.

TIERRA MEDIA — SITIO WEB
=========================
Sitio estático en HTML + CSS + JavaScript.

ESTRUCTURA
- index.html
- pages/                  -> páginas internas
- assets/css/styles.css  -> estilos generales
- assets/js/main.js      -> menú móvil, búsqueda, filtros y formulario
- assets/images/         -> reemplazá aquí tus imágenes

IMPORTANTE
El fondo principal está preparado para:
assets/images/header-anillo.jpg

El logo está preparado para:
assets/images/logo-anillo.png

Podés abrir index.html directamente en el navegador. No requiere Node, React ni servidor para funcionar.

TIPOGRAFÍAS
Se usa Cinzel + Cormorant Garamond desde Google Fonts cuando hay conexión a Internet. Si querés una versión 100% offline, descargá esas fuentes y agregalas al proyecto.

FORMULARIO
El formulario funciona como demostración visual. Para recibir mensajes reales conectalo a Formspree, EmailJS o un backend propio.
